# Gallery

Pre-generated games that load instantly, with no network call and no model. Each `*.json` file in this folder is one entry. The page reads them at build time (`src/ui/gallery-data.ts`) and shows them with the label "pre-generated".

## Schema

```json
{
  "title": "Bounce",
  "prompt": "a ball bounces around, steer a paddle to keep it in play",
  "source": "# the Octo source text ...",
  "romBase64": "En3A...",
  "note": "optional honesty note shown next to the label"
}
```

| Field | Type | Rules |
|---|---|---|
| `title` | string | Not empty. |
| `prompt` | string | The request that produced the game, or a short description. Not empty. |
| `source` | string | The Octo source. Not empty. |
| `romBase64` | string | The compiled ROM as base64. Must decode to 1 to 3584 bytes. A test checks that it equals `compile(source).rom` and passes the headless harness. |
| `note` | string, optional | Shown next to the "pre-generated" label. |

Invalid files are skipped and reported by `loadGallery`, they never break the page.

## Placeholders

`placeholder-bounce.json` and `placeholder-catch.json` are hand-written examples from `examples/`, not model output. Their titles start with "[placeholder]" and they carry a note that says so. Regenerate them with `npm run gallery:placeholders`.

Spec 6 adds 8 or more real entries (generated by a model and checked by the harness) and removes the placeholders.
